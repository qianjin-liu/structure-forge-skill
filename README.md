# Structure Forge · 聊一次，以后不用再聊

**把「跟 AI 聊了半天才对上的格式」，变成一张能反复用的小纸条。**

[English](README.en.md) · **简体中文** · [使用说明书](USAGE.md) · [完整例子](examples/weekly-report.md) · [技能文件](SKILL.md)

> 「小纸条」就是一段普通文字。复制它发给任意 AI，AI 就知道该写成什么样。
> 不用装插件、不用联网、不用学任何概念。技能文件里管它叫「结构词」，是同一个东西。

---

## 你是不是也这样过

跟 AI 来回说了十几句，它总算写对了：分几段、每段写什么、哪里别啰嗦。你挺满意。

第二天换个题目，又得从头说一遍。

更麻烦的是，你其实**说不清那个格式到底长什么样** —— 只能举例子、挑毛病、说「不是这个意思」，一点点把它逼出来。

为什么会这样？因为那个格式**只活在那一次聊天里**。窗口一关，就没了。

打个比方：你常去一家店，每次都得重新交代「不要香菜、少辣、醋多加」，服务员一换人就要重讲。你缺的不是表达能力，是一张写着这些要求的小纸条。

**这个技能就是帮你写这张纸条的。**

---

## 它到底做了什么

你把那段聊天记录（或者一份你满意的成品）丢给它，它做三件事：

1. **自己先看一遍**：从你们的对话里猜出格式有几块、每块叫什么、按什么顺序排。你不用描述，也描述不清没关系。
2. **问你几个特别好答的问题**：3–5 个，一次只问一个，每个都带好选项和推荐答案。你回一句「按推荐」就能过，不用回忆、不用总结、不用写长句。
3. **给你一张纸条**：你点头之后，它写成一段能直接发给 AI 的文字，把格式、不能写的东西、写完好怎么检查，全写清楚。

以后做同类的事，**纸条一个字都不用改，只填这次不一样的内容**。

> 说人话：**对齐只发生这一次，之后只填空。**

## 完整走一遍给你看

拿「周报」当例子。下面是真实节奏的浓缩版：

```
你：上周我跟 AI 聊了半天，它终于把周报写成我想要的样子了。帮我存下来。
    （贴上聊天记录）

它：我看了，你要的格式大概是这 5 块，顺序对吗？
    ① 标题  ② 本周完成  ③ 风险  ④ 下周计划  ⑤ 备注
    （推荐：对，就按这个）          〔第 1/5 问〕

你：按推荐

它：我从对话里找出几条「一看就不对」的，勾掉不要的就行：
    ☑ 开头写客套话   ☑ 写「总体来说」这类总结句   ☑ 自己编数据
    （推荐：都留）                〔第 2/5 问〕

你：都留

它：没做完的事，要不要统一标 [进行中]？（推荐：要）  〔第 3/5 问〕

你：要

它：格式我再给你过目一遍：标题 → 本周完成 → 风险 → 下周计划 → 备注，
    一节都不能少，标题也不能改字。可以吗？

你：可以

它：最后选个写法：A 严格照模板（推荐）／ B 大致照着来／ C 多给个例子照抄
    A 最稳，B 灵活但容易跑偏，C 适合给新手看。选哪个？

你：A

它：纸条写好了，复制走吧 ↓
```

拿到的纸条长这样（这里只截一小段，完整版见 [完整例子](examples/weekly-report.md)）：

```
写一份周报，必须包含下面 5 块，标题和顺序都不能变：
  1. 标题    2. 本周完成    3. 风险    4. 下周计划    5. 备注

不要写：开头客套话、以「总体来说」开头的总结句、没依据的数据。
没做完的事标 [进行中]。
写完自己检查：5 块齐不齐？标题有没有被改？有没有编数据？

## 这次要填的
主题：双十一复盘
本周做了：……
```

**下次写周报，上面那一大段原封不动，只改最后两行。**

## 六步，说人话就是六句话

| | 这一步在干嘛 | 你要做什么 |
|---|---|---|
| 第 1 步 | 把聊天记录整理出格式草稿 | 把材料贴进来就行 |
| 第 2 步 | 问 3–5 个好答的小问题，补齐你没说出口的要求 | 回「按推荐」或点一下选项 |
| 第 3 步 | 把格式列给你过目，**你没点头就不往下写** | 看一眼，说「可以」 |
| 第 4 步 | 给你 2–3 种写法，讲清各自好坏 | 挑一个（也可以直接选推荐的） |
| 第 5 步 | 写出纸条，并自己检查一遍 | 基本不用管 |
| 第 6 步 | 交给你，告诉你以后怎么填空 | 存好文件 |

说明书里把这六步叫 S0 到 S5，是同一件事，只是名字更正式。

**第 3 步之后它不再问你问题了**，只剩下给你确认、让你选、帮你检查 —— 同样是怕做错，但不反复折腾你。

## 三条规矩

| | 说人话 |
|---|---|
| 1 | **你没点头，它不动笔。** 不会先甩一版「你看看」出来把格式带歪。你如果说「别问了，你看着办」，它就按推荐答案直接做完，但会明明白白告诉你哪几条是它猜的。 |
| 2 | **没答的不算你同意。** 你跳过的题，它会标「这是猜的，不对我说一声就改」，绝不会写成「已跟你确认过」。 |
| 3 | **只交这一张纸条。** 不会顺手给你写方案文档、写网页、写别的东西，除非你另外要。 |

## 纸条里都写了啥

一共 11 小块，听着多，其实就是下面五类事：

| 写的是啥 | 大白话 |
|---|---|
| 这纸条干嘛用、什么时候用 | 让 AI 一上来就知道任务是什么 |
| **要写几块、每块标题叫什么、什么顺序** | 最要紧的一段，标题不许改字、不许换顺序 |
| 哪些话不能写、哪些要求一直没明说但要遵守 | 比如「别客套」「没做完要标 [进行中]」 |
| 写完了自己怎么检查 | 一张能一条条打勾的清单 |
| 信息不够时怎么办、哪些事明确不做 | 不会瞎编，缺什么就写「待补充」 |

完整的 11 小块名字（发给 AI 时用的是英文标题，不用记）：

`Purpose` 用途 · `Context` 什么场合用 · `Task` 要产出什么 · `Format` 格式（最重要）· `Constraints` 要遵守的要求 · `Prohibited` 不许写的东西 · `Gold Standard` 一份最理想的样例 · `Self-Check` 检查清单 · `Fallback` 缺信息怎么办 · `Rule Priority` 要求打架时听谁的 · `Non-Goals` 明确不做的事

最后再挂一段 `## 这次要填的`。**所谓复用，就是上面 11 块永远不动，只改最后这一段。**

## 和「直接叫 AI 帮我写个提示词」有啥不一样

| | 直接叫它写 | 用这个技能 |
|---|---|---|
| 格式从哪来 | 得你自己说清楚，或者让它猜 | 从聊天记录里自己找出来，**你说不清也能用** |
| 你踩过的坑 | 下次重新踩一遍 | 变成「不许写」那几条，一次记牢 |
| 它自己猜的地方 | 悄悄当成跟你确认过 | 明着标出来，随时能改 |
| 以后怎么用 | 翻旧聊天记录复制 | 只填这次不一样的两行 |

## 怎么装、怎么用

**装（就复制一个文件，没有依赖、不用联网）：**

```bash
mkdir -p ~/.workbuddy/skills/structure-forge
cp SKILL.md ~/.workbuddy/skills/structure-forge/SKILL.md
```

**用：** 对 AI 说「帮我把这个格式存下来」，或者「结构词」「对话转结构」「按我的格式生成」，然后把聊天记录贴进去。

**以后：** 把纸条原样发给任意 AI，只改末尾 `## 这次要填的` 那几行。

每一步具体怎么答、材料可以是哪几种、纸条怎么检查和改，都写在 **[使用说明书](USAGE.md)** 里；想看从头到尾的完整对话和整张纸条，看 **[完整例子](examples/weekly-report.md)**。

## 常见问题

**我完全不会写提示词，能用吗？**
能，而且这正是它给的。你只要会贴聊天记录、会回「按推荐」就行。

**会不会问一大堆问题？**
默认 3–5 个，一次只问一个，都带推荐答案。嫌慢可以说「一次问完」，不想答就说「别问了，你看着办」。

**换个 AI 还能用吗？**
能。纸条就是普通文字，发给谁都行，跟这个技能、跟 WorkBuddy 都没关系。

**它猜错了怎么办？**
第 3 步会把格式列给你看，那时候直接说「第 3 块不要」就行。已经存好的纸条也能直接手改，就是普通文字。

**怎么知道 AI 有没有照着写？**
把 AI 的输出贴回来，照纸条里的检查清单一条条对：块齐不齐、标题改没改、有没有写不许写的内容。

**要联网或者装什么东西吗？**
不用。装的时候复制一个文件，用的时候是 AI 在跑，纸条本身也只是文字。

## 什么时候别用

- 想要 AI **百分百**每次都一模一样 —— 做不到。检查清单只是帮你发现问题，不是质量保证，最后还得自己看一眼。
- 医疗、法律、金融这类不能出错的场景 —— 纸条里没有内置行业规矩，得自己把硬要求补进去。
- 想让它查实时资料、跑代码、替你发消息 —— 它只写字，不干这些。
- 这个仓库里只有「纸条怎么写」的说明书，没有软件；需要一个能读 `SKILL.md` 的 AI 工具来跑。
