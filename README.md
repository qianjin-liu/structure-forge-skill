# 聊一次，以后不用再聊

Structure Forge。给一段对话，还你一张能反复用的小纸条。

[English](README.en.md) · 简体中文 · [使用说明书](USAGE.md) · [完整例子](examples/weekly-report.md) · [技能文件](SKILL.md)

小纸条就是一段普通文字，复制给任意 AI，它就知道该写成什么样。不用装插件，不用联网。技能文件里管它叫「结构词」，一回事。

## 写出来是因为这件事

上周跟 AI 磨了十几轮，周报总算对了：五节，风险单独一节还得排在下周计划前面，开头别客套，没做完的标 [进行中]。当时挺满意。

这周换个主题，又从头磨一遍。

说不清自己到底要什么格式，只能一句句纠，「不是这个意思」「再改一下」。这大概是最烦的地方。

问题不在提示词写得不好。那个格式只活在那一次聊天里，窗口一关就没了。像常去的面馆，每回换服务员都得重讲一遍「不要香菜、少辣、醋多加」。缺的不是表达能力，是一张写好的纸条。

## 贴完材料，剩下的它自己跑

它先把格式猜出来：分几块，每块叫什么。顺序也一并理好。你不用描述，描述不清也没关系。

中间会问 3–5 个小问题，每个都带现成选项和推荐答案。回一句「按推荐」就够，懒得答直接跳过，它按推荐项走，并把这几条标成「我猜的」。跟着给你一段能直接发给 AI 的文字。格式和不许写的东西都在里面，写完它自己还会跑一遍检查。

以后做同类的事，那段文字一个字都不用动，只改末尾两行。

## 举一次给你看

```
我：上周跟 AI 磨了半天，周报总算写成我要的样子了。存一下。
    （贴聊天记录）

它：看完了，格式大概是这五块：标题 / 本周完成 / 风险 / 下周计划 / 备注。
    我按这个来。〔第 1 问，推荐：就按这个〕
我：嗯

它：你说过「别写客套话」「别写总体来说」，还提过别编数据，我列成三条不许写的。
    〔第 2 问，推荐：都留〕
我：都留

它：没做完的事要标 [进行中] 吧？〔第 3 问，推荐：要〕
我：要

它：五块顺序核过了，标题没改字。写法我用最稳的那套，逐块写死，方便以后核对。
    纸条在这儿 ↓
```

纸条截一小段（完整版在 [完整例子](examples/weekly-report.md)）：

```
写一份周报，必须有这 5 块，标题和顺序不能变：
  1. 标题  2. 本周完成  3. 风险  4. 下周计划  5. 备注

别写：开头客套话、以「总体来说」开头的总结句、没依据的数据。
没做完的事标 [进行中]。
写完自己检查：5 块齐不齐，标题改没改，有没有编数据。

## 这次要填的
主题：双十一复盘
本周做了：……
```

下周写周报，上面原封不动，改末尾两行。

## 中间到底要你做什么

基本没有。贴材料那一下之外，问题都带推荐答案，跳过也行。格式它自己核了一遍，每块都标着默认「保留」。写法用最稳的那套，检查也是它自己跑。

哪一步觉得不对，随口说一句，它退回去改那一段，不用从头来。说明书把这几段叫 S0 到 S5，名字正式，事儿就这些。

有两件事它比较较真。你没点头前不会先甩一版「你看看」，免得格式被带歪；你跳过的题一律标成「这是我猜的」，不写成「已跟你确认」。它只交这一张纸条，不会顺手附赠方案文档或者网页。真赶时间就说「别问了」，它按推荐答案做完，猜过的照样标出来。

## 纸条里写了啥

11 小块，算下来五件事。这纸条干嘛用，格式长什么样（最要紧，标题不许改字），哪些话不能写。还有写完怎么检查、缺信息怎么办。

发给 AI 用的是英文小标题，不用记：`Purpose` `Context` `Task` `Format` `Constraints` `Prohibited` `Gold Standard` `Self-Check` `Fallback` `Rule Priority` `Non-Goals`。末尾挂一段「这次要填的」。复用就是上面不动，只改这一段。

直接叫 AI 写提示词，格式得你说清楚，说不清就让它猜。这个是从聊天记录里找出来的，连你说「不是这个意思」的地方都能变成不许写的条款。以前踩过的坑记一次就够，也不用翻旧聊天记录。

## 装一次，用很久

把 `SKILL.md` 放进 `~/.workbuddy/skills/structure-forge/`，重启会话。就这一次，没有依赖，不用联网。

```bash
mkdir -p ~/.workbuddy/skills/structure-forge
cp SKILL.md ~/.workbuddy/skills/structure-forge/SKILL.md
```

用的时候说一句「把这个格式存下来」，聊天记录贴进去。之后把纸条原样发给任意 AI，改末尾两行。

每一步的细节在 [使用说明书](USAGE.md)，从头到尾的对话和整张纸条在 [完整例子](examples/weekly-report.md)。

## 大概会问的几件事

不会写提示词能用吗？能，要的就是你不会写。贴记录、回「按推荐」，够了。

会问很多吗？3–5 个，一次一个，都带推荐答案，跳过也行。

换个 AI 还能用吗？能，纸条就是普通文字，跟这个技能、跟 WorkBuddy 都没关系。

猜错了怎么办？格式摆出来那会儿说一句「第三节不要」就行。存好的纸条也是普通文字，直接手改。

要联网吗？不用。装的时候复制一个文件，纸条本身只是文字。

## 有些事它做不到

想要每次一模一样，做不到。检查清单是让 AI 自己先过一遍，看一眼这步省不掉。

医疗、法律、金融这类场景，纸条里没有现成的行业规矩。它只写字，查资料和跑代码这类事不在里面。仓库里是规则和文档，不是软件，得有一个能读 `SKILL.md` 的 AI 工具来跑。

说明书和完整例子目前只有中文。
