# 完整走查：一段纠偏对话 → 一份可复用结构词

下面走一遍 `structure-forge` 的 S0 到 S5。输入是一段「说了好多话 AI 才对上」的对话，输出是一份之后只填变量的结构词。

---

## 输入：原始纠偏对话

```
我：帮我写这周周报
AI：好的！本周工作顺利推进，团队氛围融洽……（一大段）
我：不是，不要这种开场白，直接一点
AI：好的，本周完成：…… 下周计划：……
我：太简了，我要分节，而且每节下面要有具体事项
AI：# 周报 / ## 本周完成 / - 事项…… / ## 下周计划
我：接近了，但少了风险，风险要单独一节，放在下周计划前面
AI：# 周报 / ## 本周完成 / - 事项…… / ## 风险 / ## 下周计划
我：对，就这个。另外每节别超过 5 条，不要写「总体来说」这种总结句，
    没做完的事要标 [进行中]，别自己编进度。
AI：（照做，用户满意）
```

麻烦的是，明天换个主题又得重来一遍。

---

## S0 输入归一：反推候选骨架

从最后一版输出里识别标题与列表，得到节点表：

| 层级 | 名称 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| L1 | 周报 | section | 是 | 文档标题 |
| L2 | 本周完成 | section | 是 | 已完成事项，≤5 条 |
| L3 | 事项 | field | 是 | 具体事项；未完成标 `[进行中]` |
| L2 | 风险 | section | 是 | 风险与阻塞，位置固定在下周计划之前 |
| L2 | 下周计划 | section | 是 | 下周待办，≤5 条 |

> 注意：S0 只取标题与字段名，**不把对话正文塞进骨架**。
> 「不要开场白」「不要总结句」「别编进度」这些不是结构，留给 S1 转成禁止项。

---

## S1 意图显影：3–5 轮渐进轻对话

本例走满 5 轮。每轮只问 1 件事，候选与推荐项由 agent 先从原始对话里抽好，用户不需要回忆、归纳或写长文本。

```
【第 1/5 问 · 还剩 4 问】我从最后一版输出里反推出 5 个节点：
  周报 / 本周完成 / 事项 / 风险 / 下周计划
  ① 对，就是这些（推荐）  ② 少了一节  ③ 多了一节
用户：对
→ 已记下：骨架 5 节点，顺序固定。

【第 2/5 问 · 还剩 3 问】从你说「不是 / 不要 / 别」的地方抽到这些跑偏信号，
  勾掉不要的，或直接说「都留」：
  ☑ 开头写客套话                      ☑ 写「总体来说」这类总结句
  ☑ 把「风险」和「下周计划」合并成一节   ☑ 任一节超过 5 条
  ☑ 自己编进度或数据                  （推荐：都留）
用户：都留
→ 已记下 5 条 Prohibited。

【第 3/5 问 · 还剩 2 问】我猜这些是你默认、但从没单独明说过的：
  ☑ 风险必须单独一节，而且永远排在下周计划前面
  ☑ 未做完的事标 [进行中]，不能写成已完成
  ① 都对（推荐）  ② 补一条
用户：都对
→ 已记下 2 条 Constraints。

【第 4/5 问 · 还剩 1 问】两个小选择：
  ① 结构范围 （推荐）仅保留骨架不外扩 / 允许补章节并标 [新增] / 自由组织
  ② 严格程度 （推荐）字段级严格 / 章节级严格 / 宽松
用户：按推荐
→ 已记下：范围=不外扩，程度=字段级严格。

【第 5/5 问 · 最后一问】最后三个：
  ③ 输出格式 （推荐）Markdown / JSON / 纯文本表格
  ④ 目标受众 （推荐）自己复用 / 团队统一口径 / 喂给下游系统
  ⑤ 完成标准 （推荐）字段齐全 + 跑自检 / 字段齐全即可 / 附变更说明
用户：按推荐，④ 改成团队统一口径
→ 已记下，其余按推荐。
```

### 复述约定 + 假设声明块

每轮结束各有一行短复述；全部轮次走完后，agent 一次性复述完整约定：

```
确认约定：
- 范围：仅保留 5 个骨架节点，不外扩
- 程度：字段级严格，标题逐字一致
- 格式：Markdown
- 受众：团队统一口径
- 验收：字段齐全 + 跑自检清单
- 禁止项：5 条（客套开场白 / 总结句 / 合并风险与计划 / 超 5 条 / 编进度）
- 隐含前提：风险单独成节且在前；未完成标 [进行中]
```

本例五轮全部回答，**无【假设】**，因此不生成假设声明块。若用户在第 5 轮回「跳过」，则会出现：

```
> 本次假设（未经确认，按推荐项执行）
> 1. 输出格式：Markdown — 若团队实际需要 JSON，说一句我改，骨架不受影响
```

## S2 结构共识：唯一硬门禁

设计树按前沿分轮呈现（本例 5 个节点，一轮即可）：

```
第 1 轮前沿（5 个待决节点）
[✓] ▦ 周报         章节 · 必填 · 推荐：保留
[✓]   ▦ 本周完成    章节 · 必填 · 推荐：保留
[✓]     · 事项      字段 · 必填 · 推荐：保留
[✓]   ▦ 风险        章节 · 必填 · 推荐：保留（位置固定在下周计划前）
[✓]   ▦ 下周计划    章节 · 必填 · 推荐：保留
```

`已确认 5 / 5` → 前沿为空 → 门禁放行。**在此之前 agent 不许给出结构词正文。**

## S3 表达选型：带权衡 + 做减法

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A 严格模板式（推荐）** | 逐字段声明必填、顺序、格式 | 复现度最高，可机械校验 | 略长，自由度低 |
| B 宽松要点式 | 只留章节标题 | 短、灵活 | 易漂移，只能查标题 |
| C 示例驱动式 | 以样本为主 | 语气最像 | 换主题容易连内容照抄 |

用户选 **A**。

YAGNI「明确不做」清单：

```
不生成结构之外的解释与总结
不替我补我没提供的进度或数据
不改动骨架里的标题文字
不调整「风险」与「下周计划」的顺序
```

## S4 落笔与自证：最终结构词

````markdown
# 周报结构 · 结构化输出指令 v1.0

## Purpose
让模型一次就按固定的周报结构产出，不再靠长对话反复纠偏；团队所有人输出同一形状。

## Context
使用者：团队统一口径。本结构来自一次已对齐的对话，以下约定均为已确认事实，不需要再次推断。
触发场景：每周写周报时。

## Task
依据「本次输入」完成本周周报，并严格按 Format 中的骨架组织输出。
只写骨架要求的内容，不写前言、不写总结、不解释为什么这样组织。

## Format
以下 5 个节点必须全部出现，顺序、层级、标题文字均不得改动：

1. 周报 〔必填 · 文档标题〕
  2. 本周完成 〔必填 · 已完成事项，≤5 条〕
    - 事项 〔必填 · 具体事项；未完成标 [进行中]〕
  2. 风险 〔必填 · 风险与阻塞，位置固定在下周计划之前〕
  2. 下周计划 〔必填 · 下周待办，≤5 条〕

## Constraints
- 结构范围：仅保留以上骨架，不外扩，不新增章节
- 严格程度：字段级严格，标题逐字一致，顺序不变
- 输出格式：Markdown
- 完成标准：字段齐全 + 跑一遍 Self-Check
- 每节不超过 5 条
- 未提供的事实不得脑补；缺信息处写 [待补充：缺什么]
- 隐含前提（现显式化）：风险必须单独一节且永远排在下周计划之前
- 隐含前提（现显式化）：未做完的事标 [进行中]，不得写成已完成

## Prohibited
- 开头写客套话
- 把「风险」和「下周计划」合并成一节
- 写「总体来说」这类总结句
- 自己编进度或数据
- 任一节超过 5 条

## Gold Standard
# 周报
## 本周完成
- 完成渠道结算对账
- 用户访谈 3 场
- 报表字段梳理 [进行中]
## 风险
- 数据口径未与财务对齐，可能影响复盘结论
## 下周计划
- 完成渠道复盘初稿
- 与财务确认口径

## Self-Check
- [ ] 5 个节点全部出现，顺序一致
- [ ] 5 个必填项无遗漏、无空节
- [ ] 标题文字与 Format 完全一致，未改写
- [ ] 「风险」位于「下周计划」之前，且未与之合并
- [ ] 未出现任何 Prohibited 中的写法
- [ ] 每节 ≤5 条
- [ ] 没有 [待补充] 之外的编造内容
- [ ] 未做完的事标了 [进行中]
如有任一项不满足，先修正再输出，不要输出后附注说明。

## Fallback
- 输入不足以支撑某一节：保留该节标题，正文写 [待补充：缺什么]，不要跳过该节。
- 结构要求与内容质量冲突：优先保结构，末尾单列「本次偏差」一行说明。

## Rule Priority
安全 > 用户硬约束 > 领域规则 > 通用规则

## Non-Goals
- 不生成结构之外的解释与总结
- 不替我补我没提供的进度或数据
- 不改动骨架里的标题文字
- 不调整「风险」与「下周计划」的顺序

## 本次输入（变量）
主题：第 46 周研发周报
材料：<粘贴本周事项>
要求：重点写风险，其他从简
````

## S5 复用：只换变量

下周要写第 47 周周报时，**上面 11 段一个字不动**，只改末尾：

```markdown
## 本次输入（变量）
主题：第 47 周研发周报
材料：完成灰度发布；压测报告待出；两名同事请假
要求：正常详略
```

把整份结构词连同这一段发给任意 AI。不需要带原始对话，不需要重述「分几节」「风险放哪」。

## 校验：把输出贴回来逐项核对

假设模型返回了这样一段（含两个问题）：

```markdown
总体来说，本周工作稳步推进。# 周报
## 本周完成
- 完成灰度发布
## 下周计划
- 出压测报告
## 风险
- 人手紧张
```

逐项核对结果：

| 检查项 | 结果 |
|---|---|
| 5 个节点齐全 | ✕ 缺「事项」字段层级说明 |
| 顺序一致 | ✕ 「风险」被排到了「下周计划」之后 |
| 标题逐字一致 | ✓ |
| 禁止项命中 | ✕ 命中「总体来说」；✕ 命中「风险与下周计划顺序错误」 |
| 每节 ≤5 条 | ✓ |
| 未编造内容 | ✕ 「稳步推进」属于未经提供的评价 |

结构吻合度约 `60%`，命中 2 条禁止项 → 不通过。把 `Self-Check` 单独再发一次要求修正，或把变量写得更明确即可。
